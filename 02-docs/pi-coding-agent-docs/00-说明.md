## 一、任务类型与目标

- **任务类型**：本地源码文档二次整理（英文原文存档 + 简体中文主题整理 + 离线导航索引）。
- **目标**：从 `pi-main` 仓库的 `packages/coding-agent/docs` 目录（pi coding-agent 官方使用与集成文档全集）整理一份可读性更高的中文学习资料，方便学习 Pi 的使用与集成方案。断网环境下打开 [01-索引.md](01-索引.md) 即可按主题阅读全部中文整理页，并随时对照 `source/` 中的英文原文存档。
- **来源位置**：`01-projects/pi-main/packages/coding-agent/docs/`。
- **整理日期**：2026-11-01。

## 二、收集范围

- **收录**：pi-coding-agent 官方文档全部 42 个 Markdown 页面 + 站点导航配置 `docs.json` + 4 张文档插图（`images/`）。
- **文档版本**：`@earendil-works/pi-coding-agent` **v1.4.0**（来自 `pi-main/packages/coding-agent/package.json`）。

## 四、处理流程

- **英文存档**：将 `docs/` 全部文件原样复制到 `source/`（43 个 md/json + `images/` 4 张图），未做任何改写，保证原文可查。
- **中文主题页**：按主题把相关原始页面聚合为一页，采用「原文存档：source/X.md」链接开头的小节结构；页间与存档间全部使用相对链接互链。
- **整理规范**：中文页为**二次整理**而非逐字翻译——提炼使用要点、配置项、命令和集成方式，保留关键英文术语（命令、flag、配置键、API 名称、包名、路径）便于对照原文；叙述性文字用简体中文。

## 五、验证记录

- 主题页 02–11 共 10 页，覆盖 42 个来源文件（docs.json 为辅助导航不单独成节）。
- 每页小节以「原文存档：source/X.md」精确行开头；相对链接指向 `source/` 中实际存在的文件。
- 中文页不含外链与图片引用，原文插图以「见 source/images/xxx.png」文字标注。

## 六、整理说明（如实的限制记录）

1. 中文页对超长原始文档（如 extensions.md、settings.md、cli.md）做**要点提炼**，细节以原文存档为准；遇到歧义以原文为准。
2. 原文中的站内相对链接（如 `cli.md#mcp-commands`）在中文页中改为指向本资料集对应小节或纯文本路径；`source/` 存档保持原样。
3. 版本差异：Pi 迭代较快（v1.4.0），后续若 pi-main 更新，本资料集中文页可能滞后；更新时以最新原文存档为基准重核。
