# 04 配置与设置

> 本页覆盖：配置总览与文件位置（configuration）、全部设置项参考（settings）、环境变量（environment-variables）。读完本页能自己搭出一套完整的 Pi 配置。

## configuration.md — 配置总览

> 原文存档：[source/configuration.md](source/configuration.md)

**两级配置**：

- **用户级**：agent 目录（默认 `~/.pi/agent`，可用 `PI_CODING_AGENT_DIR` 或 SDK `agentDir` 覆盖）。
- **项目级**：工作目录下的 `.pi/`，**在项目被信任后**才加载（见 10 页 security）。唯一例外是 `sessionDir`（信任判定前就读，用于定位会话）。

**agent 目录文件职责**：

| 路径 | 职责 |
| --- | --- |
| `<agent-dir>/settings.json` | 用户级设置（偏好、默认、资源路径、Pi 包声明） |
| `<agent-dir>/keybindings.json` | 自定义快捷键 |
| `<agent-dir>/mcp.json` | 全局可用 MCP 服务器 |
| `<agent-dir>/models.json` | 兼容端点、模型、modelOverrides |
| `<agent-dir>/auth.json` | 已存 API Key 与 OAuth 凭据（隐私） |
| `<agent-dir>/AGENTS.override.md` / `AGENTS.md` / `CLAUDE.md` | 跨工作目录的用户指令 |
| `<agent-dir>/SYSTEM.md` | 替换 Pi 默认系统提示词 |
| `<agent-dir>/APPEND_SYSTEM.md` | 追加到系统提示词 |
| `<agent-dir>/extensions/` `skills/` `prompts/` `themes/` | 用户扩展/技能/提示模板/主题 |

**项目 `.pi/` 目录**：同样的 `settings.json` / `mcp.json` / `SYSTEM.md` / `APPEND_SYSTEM.md` / `extensions/` / `skills/` / `prompts/` / `themes/`。`SYSTEM.md`/`APPEND_SYSTEM.md` 中**受信任的项目文件优先于 agent 目录对应文件**，同名文件不合并。

**上下文文件（context files）**：`AGENTS.md` / `CLAUDE.md` 从 agent 目录、工作目录及其父目录加载，作用于该目录及其下所有运行。`AGENTS.override.md` 只替换同目录的 `AGENTS.md`/`CLAUDE.md`。**上下文文件发现不要求项目信任**。

**交互修改**：`/settings` 改常用偏好；其余直接编辑文件后 `/reload`（重载 settings/keybindings/instructions/resources）。

## settings.md — 设置参考

> 原文存档：[source/settings.md](source/settings.md)

文件：`settings.json`，可加 `$schema` 校验。**项目设置覆盖用户设置**；资源列表合并（不是覆盖）。

### 模型与思考

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| `defaultProvider` / `defaultModel` | 自动 | 启动时使用的提供方 / 模型 |
| `defaultThinkingLevel` | `medium` | 启动思考级别（off/minimal/low/medium/high/xhigh/max） |
| `modelThinkingLevels` | 无 | 按 `provider/modelId` 精确匹配的启动级别 |
| `thinkingBudgets` | 内置 | minimal/low/medium/high 各级别 token 预算 |
| `enabledModels` | 全部 | 启动选择与模型循环的模型模式（同 `--models` 格式） |
| `hideThinkingBlock` | `false` | 隐藏思考块 |
| `showCacheMissNotices` | `false` | 显示缓存未命中/预热/压缩等提示 |
| `cacheWarming` | `streaming` | 缓存预热：运行期间（streaming）或运行间（idle） |

> 缓存预热仅在模型声明了缓存保留时长、且预计省下 ≥$0.05 缓存未命中成本时运行。

### 交互

- `steeringMode` / `followUpMode`：`all` 或 `one-at-a-time`（默认），排队消息的投递方式。
- `externalEditor`：外部编辑器命令（`$VISUAL` → `$EDITOR` → 平台默认）。
- `doubleEscapeAction`：`tree`（默认）/ `fork` / `none`，编辑器为空时双击 Esc 的动作。
- `treeFilterMode`：`/tree` 初始过滤（default/no-tools/user-only/labeled-only/all）。
- `defaultProjectTrust`：`ask`（默认）/ `always` / `never`，**仅限 agent 目录设置**。

### 工具

- `defaultTools`：默认 `read`、`bash`、`edit`、`write`。纯名字整体替换默认；`+name` 追加、`-name` 移除；空数组禁用全部内置工具（扩展/SDK 工具不受影响）。例：`["+codemode"]` 在默认工具旁启用 codemode。
- 可用内置工具：`read`、`bash`、`powershell`、`edit`、`write`、`grep`、`find`、`ls`，另有 `codemode`、`tool_search`。
- `codemode.mode`：`on`（默认，codemode 只列出未声明的工具）/ `only`（codemode 列出全部可调用工具，内置工具对模型隐藏，模型通过 codemode 触达）。
- `codemode.inlineBudget`：默认 `3000`，codemode 工具描述中工具声明的 token 预算（字符/4）。
- `/reload` 只启用新增工具，不关闭被移除的工具；`--tools` / `--no-tools` / `--no-builtin-tools` 覆盖本设置。

### 会话与上下文

- `sessionDir`：会话存储目录（`PI_CODING_AGENT_SESSION_DIR` 与 `--session-dir` 优先）。
- `sessionShareDestination`：`auto`（默认，有 Radius 用 Radius，否则 GitHub gist）/ `gist` / `radius`。
- `compaction.enabled`（`true`）、`compaction.reserveTokens`（`16384`，低于该空闲 token 开始自动压缩）、`compaction.keepRecentTokens`（`20000`，保留不摘要的最近 token）、`compaction.modelOverrides`（按模型覆盖）。
- `branchSummary.reserveTokens`（`16384`）、`branchSummary.skipPrompt`（`false`）。

### 终端与显示

- `theme`：`system`（默认，跟随终端）/ `dark` / `light` / 自定义主题名。
- `quietStartup`：`false` / `true` / `"header"`（只保留版本头）。
- `tuiMode`：`fullscreen`（默认）/ `regular`。
- `fullscreenExitOutput`（`transcript`/`resume-hint`）、`fullscreenScrollbar`、`fullscreenCopyOnSelect`（`true`）、`fullscreenWheelScrollLines`。
- `editorPaddingX`、`outputPad`、`autocompleteMaxVisible`、`showHardwareCursor`。
- `terminal.showImages`（`true`）、`terminal.imageWidthCells`（`60`）、`terminal.clearOnShrink`、`terminal.showTerminalProgress`、`terminal.hyperlinks`、`terminal.images`、`terminal.trueColor`。
- `images.autoResize`（`true`，>2000×2000 先缩放）、`images.blockImages`（`false`）。
- `markdown.codeBlockIndent`（`"  "`）、`markdown.mermaid`（`streaming`/`final`/`off`）。

### 网络与重试

- `transport`：`auto` / `sse` / `websocket` / `websocket-cached`。
- `httpProxy`（**仅 agent 目录**）、`httpIdleTimeoutMs`（`300000`）、`websocketConnectTimeoutMs`（`15000`）。
- `retry.enabled`（`true`）、`retry.maxRetries`（`3`）、`retry.baseDelayMs`（`2000`）、`retry.maxAgentDelayMs`（`60000`）。
- `retry.provider.*`：提供方级重试（`maxRetries` 默认 `0`——保持 0，让 Pi 自己处理配额与用量限制错误）。

### Shell

- `shellPath`（自定义 shell）、`shellCommandPrefix`（每条命令前缀）、`npmCommand`（npm 查找/安装命令）、`selfUpdateCommand`（`pi update` 的自更新命令，占位符 `{packageName}` `{version}` `{installSpec}`，**仅 agent 目录**）。

### 资源

- `packages` / `extensions` / `skills` / `prompts` / `themes`：资源路径数组；支持 `!pattern` 排除、`+path` 精确包含、`-path` 精确排除。用户级与项目级资源**合并加载**。
- `enableSkillCommands`（`true`）：把技能注册为 `/skill:name` 命令。
- 内置扩展名：`builtin:mcp`、`builtin:llama.cpp`、`builtin:codemode`、`builtin:tool-search`；`-builtin:mcp` 禁用其一；`--no-extensions` 全部禁用；`-e builtin:<name>` 显式加载。

### 更新、遥测与警告

- `collapseChangelog`（`false`）、`enableInstallTelemetry`（`true`，匿名安装/更新上报与提供方归属头）、`enableAnalytics`（`false`）、`warnings.anthropicExtraUsage`（`true`）。

## environment-variables.md — 环境变量

> 原文存档：[source/environment-variables.md](source/environment-variables.md)

**进程标记（子进程可识别 Pi）**：

- `AI_AGENT=pi`：通用标记，标识 Pi 是启动进程的 agent。
- `PI_CODING_AGENT=true`：Pi 专属标记。二者由 CLI/RPC 入口设置并被子进程继承；**SDK 内嵌时不会自动设置**。

**shell 工具会话环境**（`bash`/`powershell` 工具执行的命令可读取，每次命令启动时解析）：

| 变量 | 说明 |
| --- | --- |
| `PI_SESSION_ID` | 当前会话 ID |
| `PI_SESSION_FILE` | 当前会话 JSONL 文件绝对路径（临时会话不设置） |
| `PI_PROVIDER` | 当前模型提供方 |
| `PI_MODEL` | 当前模型 ID |
| `PI_REASONING_LEVEL` | 当前思考级别（off~max） |

- 判断"当前用的什么模型"应查这些变量，别猜系统提示词；切模型后下一条命令即生效。
- 注入到 LLM 可调用的 `bash`/`powershell` 工具，**不注入**用户输入的 `!` / `!!` 命令。
- 自定义 shell 工具（`createBashTool()` / `createPowerShellTool()`）默认也注入；`exposeSessionEnvironment: false` 可关闭（关闭时清除继承值，防嵌套 Pi 泄漏父会话元数据）；注入发生在 `spawnHook` 之前。

**Pi 进程配置变量**（节选，完整见原文）：

| 变量 | 说明 |
| --- | --- |
| `PI_CODING_AGENT_DIR` | 覆盖配置目录（默认 `~/.pi/agent`） |
| `PI_CODING_AGENT_SESSION_DIR` | 覆盖会话存储（`--session-dir` 更优先） |
| `PI_PACKAGE_DIR` | 覆盖包目录（Nix/Guix store 场景） |
| `PI_OFFLINE` | 禁用自动网络活动（含模型目录刷新） |
| `PI_SKIP_VERSION_CHECK` | 跳过 pi.dev 版本检查 |
| `PI_SELF_UPDATE_COMMAND` | 自更新命令（优先于 `selfUpdateCommand` 设置） |
| `PI_TELEMETRY` | 覆盖安装/更新遥测与归属头（1/0） |
| `PI_CODEMODE_MAX_WORKERS` | 进程内 codemode worker 上限（默认 2，每个 ≤256MB） |
| `PI_CACHE_RETENTION` | 设为 `long` 启用长期提示缓存 |
| `PI_SHARE_VIEWER_URL` / `PI_RADIUS_GATEWAY` | 覆盖 `/share` 基址 / `/bug` 上传网关 |
| `PI_CLEAR_ON_SHRINK` / `PI_HARDWARE_CURSOR` / `PI_CLIPBOARD_OSC52` / `PI_HYPERLINKS` / `PI_PROGRAM_STATUS` / `PI_IMAGE_PROTOCOL` / `PI_TRUE_COLOR` / `PI_TUI_ESC_TIMEOUT` | 终端能力覆盖与行为开关（SSH 下 Esc 超时默认 100ms，本地 10ms） |
| `VISUAL` / `EDITOR` | `externalEditor` 未设时的编辑器回退 |
| `HTTP_PROXY` / `HTTPS_PROXY` | 出站代理 |

提供方 API Key 变量（`ANTHROPIC_API_KEY` 等）见 03 页 providers 小节。
