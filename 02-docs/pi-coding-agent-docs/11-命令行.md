# 11 命令行

> 本页覆盖：`pi` CLI 全部命令与选项（调用/输出、模型、会话、工具、资源、提示与进程、包、凭据、MCP）。具体版本的精确接口以 `pi --help` 为准（帮助里还含已加载扩展注册的 flag）。

## cli.md — 命令行参考

> 原文存档：[source/cli.md](source/cli.md)

**命令总览**：

```sh
pi [options] [--] [@files...] [messages...]
pi install <source> [options]
pi remove <source> [options]
pi uninstall <source> [options]
pi update [target] [options]
pi list
pi config [options]
pi auth <check|print-api-key|print-bearer-token> [options]
pi mcp <add|remove|list|login|logout> [options]
```

### 调用与输出

| 输入 | 行为 |
| --- | --- |
| `message` | 初始提示词 |
| `@path` | 首个 prompt 里包含文本文件或图片（从当前工作目录解析） |
| Piped stdin | 其内容前置到首个 prompt |
| `--` | 停止选项解析，让 prompt 可以 `-` 开头 |

- 终端 stdin/stdout 时开 TUI，除非 `--print` / `--mode json` / `--mode rpc`；任一流被重定向且未选 JSON/RPC 时用 print 模式。
- `-p`, `--print`：跑完打印最终文本退出；`--mode text` 只选文本输出（终端对终端仍开 TUI）；`--mode json` 输出 JSONL 事件后退出；`--mode rpc` 长驻读 stdin 命令写 stdout 响应/事件；`--export <input> [output]` 把会话文件导出 HTML 后退出。
- RPC 模式拒绝 `@file` 参数。

### 模型选项

```sh
pi --model sonnet:high
```

- `--provider <name>`：限定 `--model` 查找范围（需 `--model`）。
- `--model <pattern>`：精确 id 或模糊 id/名称匹配；接受 `provider/id` 与可选 `:<thinking>` 后缀；多提供方匹配时优先有凭据者，否则要 `--provider`。
- `--api-key <key>`：非持久 API-key 覆盖（需 `--model`/`--models` 选了模型；不替你在同模型的提供方间选择）。
- `--thinking <level>`：off/minimal/low/medium/high/xhigh/max；覆盖 `--model` 后缀并被模型能力钳制。
- `--models <patterns>`：逗号分隔的启动与循环作用域；精确 id/模糊匹配/大小写不敏感 glob/可选 `:<thinking>`；多提供方同模型各加一次并警告。
- `--list-models [search]`：列出可用模型（可模糊过滤）后退出。

### 会话选项

```sh
pi --continue
```

- `-c`, `--continue`：继续当前目录最近会话。
- `-r`, `--resume`：打开会话选择器，在会话自己的工作目录续；Tab 包含其他目录会话。
- `--session <path|id>`：按路径或完整/部分 id 开会话并在其目录续；id 只匹配其他目录存储的会话时提议 fork 进当前目录。
- `--session-id <id>`：开当前目录该 id 的现有会话，否则新建（id 限字母/数字/`.`/`_`/`-`）。
- `--fork <path|id>`：把会话 fork 成当前目录新会话。
- `--session-dir <dir>`：覆盖存储与查找（优先于 `PI_CODING_AGENT_SESSION_DIR` 与 `sessionDir` 设置）。
- `--no-session`：内存会话不持久化。
- `-n`, `--name <name>`：会话显示名。

约束：id 首尾必须字母/数字；`--fork` 不能与 `--session`/`--continue`/`--resume`/`--no-session` 组合；`--session-id` 不能与 `--session`/`--continue`/`--resume` 组合（可与 `--fork` 组合选新 id）。

### 工具选项

```sh
pi --tools read,grep,find,ls --print "Review this project"
```

- `-t`, `--tools <list>`：逗号分隔白名单（工具名或 `*` 模式）；**纯 `+name`/`-name` 列表不是白名单**，而是修改默认选择（`--tools +codemode,-write` 保留其余默认工具）；明文与 `+/-` 条目不能混用。MCP 工具默认保留，除非条目以 `mcp__` 开头。
- `-xt`, `--exclude-tools <list>`：在所有选择之后禁用（含 MCP）。
- `-nbt`, `--no-builtin-tools`：禁用内置工具，保留扩展/自定义。
- `-nt`, `--no-tools`：全部工具（内置/扩展/自定义/MCP）禁用。

默认启用 `read`/`bash`/`edit`/`write`（除非 `defaultTools` 改）。内置工具：read（读文本/图片）、bash、powershell（Windows）、edit（精确替换）、write、grep、find（glob）、ls。内置扩展再加两个（默认关，MCP 需要时自动开）：`codemode`（跑 JS 并行调工具、只有脚本输出进模型）、`tool_search`（搜索未声明的 codemode/deferred 工具并为下轮声明）。

**启用 codemode**：settings 加 `"defaultTools": ["+codemode"]`（保留默认工具并加 codemode）或单次 `pi --tools +codemode`。**工具搜索**：`"defaultTools": ["+tool_search"]`，排序同 `searchTools()`。

### 资源选项

```sh
pi --extension ./review.ts
```

- `-e`, `--extension <path>`：加载扩展文件/目录或内置扩展（如 `builtin:mcp`），可重复。
- `-ne`, `--no-extensions`：禁用发现/配置/内置扩展；显式 `-e` 仍加载（`pi -ne -e builtin:mcp` 只留内置 MCP）。
- `--no-mcp`：本 run 禁用内置 MCP 支持（不连服务器、无 MCP 工具与 `/mcp`；不影响替换内置 MCP 的扩展）。
- `--skill <path>` / `-ns`, `--no-skills`、`--prompt-template <path>` / `-np`、`--theme <path>` / `--use-theme <name[/name]>` / `--no-themes`、`-nc`, `--no-context-files`（禁 AGENTS.md/CLAUDE.md 发现）：同模式——显式路径仍加载。
- 资源路径只对当前进程有效，相对路径按当前工作目录解析。

### 提示与进程选项

```sh
pi --append-system-prompt ./instructions.md
```

- `--system-prompt <text|path>`：替换默认系统提示词；`--append-system-prompt`：追加（可重复）。
- `--tui-mode <mode>`：`fullscreen`（默认）/ `regular`。
- `--verbose`：显示详细交互启动信息（覆盖 quietStartup）。
- `-a`, `--approve` / `-na`, `--no-approve`：本进程信任/忽略受信任门控的项目本地配置与资源。
- `--offline`：禁用自动网络活动（含模型目录刷新），等价 `PI_OFFLINE=1`。
- `-h`, `--help`（含扩展注册 flag）/ `-v`, `--version`。
- 扩展可注册额外长选项；未知短选项被拒。

### 包命令

```sh
pi install npm:@scope/package
```

| 任务 | 命令 |
| --- | --- |
| 安装包 | `pi install <source>` |
| 列出配置包 | `pi list` |
| 移除包及设置条目 | `pi remove <source>`（别名 `uninstall`） |
| 配置包资源加载 | `pi config` |

`install/remove/uninstall/config` 加 `--local`/`-l` 用项目设置而非全局。更新：`pi update`（Pi 自身）/ `--extensions`（所有包）/ `<source>`（单个）/ `--models`（刷新模型目录）/ `--all`（Pi+所有包）；`--force` 重装 Pi。非 npm 提供（如 Nix）时不能 `pi update` 更新自身——用该包管理器（`nix profile upgrade pi`）；wrapper 场景设 `PI_SELF_UPDATE_COMMAND` 或 settings `selfUpdateCommand`（argv 数组）自定义更新命令。

### 凭据命令

```sh
pi auth check --provider openai --json
```

需 `--provider <provider>` 或 `--model <model>`。`pi auth check`：输出 ready/not_ready/invalid，退出码 0/1/2；`--json` 结构化输出、`--credentials` 就绪时输出凭据、`--no-refresh` 不刷新过期 OAuth。`pi auth print-api-key` 打印解析出的 API key；`print-bearer-token` 打印 OAuth bearer（`--min-expiry <duration>` 要求剩余寿命，如 `30m`）。**注意：打印凭据命令把密钥写到 stdout。**

### MCP 命令（无会话可用，agent 可经 bash 跑）

| 命令 | 说明 |
| --- | --- |
| `pi mcp add <server> [opts] -- <command> [args...]` | 添加/替换 stdio 服务器；`--env KEY=VALUE`（可重复）、`--cwd` |
| `pi mcp add <server> [opts] --url <url>` | 添加/替换 streamable HTTP 服务器；`--header`、`--bearer-token-env-var <NAME>`、`--oauth-client-id/secret/callback-port/client-name/client-registration`（auto/cimd/dcr） |
| `pi mcp remove <server>` | 移除（保留已存 OAuth 凭据） |
| `pi mcp list [--json]` | 连接所有启用服务器打印状态/工具/错误；有非法条目或未连接则退出 1 |
| `pi mcp login <server> [-l] [--timeout <秒>]` | OAuth 登录（默认 300 秒；`-l` 要求服务器定义在项目 `.pi/mcp.json`） |
| `pi mcp logout <server> [-l]` | 删除 OAuth 凭据 |

`add`/`remove` 改 `~/.pi/agent/mcp.json`（`-l` 写当前目录 `.pi/mcp.json`）；`add` 还支持 `--exposure <mode>` 与 `--description`，不连接（用 `pi mcp list` 检查）。项目 `.pi/mcp.json` 只对已信任项目读取。
