# 01 索引（资料集导航）

## 使用说明

- 本资料集为**离线使用**设计：将 `pi-coding-agent-docs` 整个目录拷贝即可，无需外网。断网环境下从本文件开始阅读。
- 文件构成：00 说明（资料集元信息、来源清单）+ 本索引 + 10 个中文主题页（02–11）+ `source/`（43 个英文原文存档 + `images/` 4 张插图）。
- 中文页内每个小节以「原文存档：source/X.md」链接开头，点击可对照英文原文；页间以相对链接互链。
