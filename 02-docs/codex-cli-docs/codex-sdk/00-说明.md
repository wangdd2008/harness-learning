# codex-sdk 分类说明

本分类整理自原收集任务 `004-codex-sdk-appserver`（2026-10-31 归档至 02-docs 时按产品大类拆分），收录 **Codex SDK** 与 **Codex Security SDK** 相关内容。

## 一、任务类型与目标

- **任务类型**：材料收集（中文资料离线化）—— 收集 OpenAI Codex **Codex SDK** 与 **Codex Security SDK** 的中文文档，整理为可离线分发的中文资料，用于迁移到无外网的内网环境。
- **目标**：
  1. **Codex SDK** — https://www.codex-docs.com/docs/codex-sdk（以编程方式控制本地 Codex 智能体：TypeScript 库、Python 库、沙箱预设）。
  2. **Codex Security TypeScript SDK** — https://www.codex-docs.com/docs/security/sdk（安全扫描 SDK，属 SDK 产品线，一并收录）。
- 说明：本分类**不重复**收集 Codex CLI 产品文档（见同域 `codex-cli/`）；Codex App Server 见同域 `code-app-server/`。

## 二、来源与抓取记录（2026-10-31）

- 来源站点：**https://www.codex-docs.com**（第三方整理的中文文档站，内容本身为中文）。
- 主通道：PowerShell Invoke-WebRequest 走本机代理（http://127.0.0.1:7897）抓取 `.md` 孪生端点（`https://www.codex-docs.com/docs/codex-sdk.md`、`https://www.codex-docs.com/docs/security/sdk.md`），成功。
- 备用通道：web_fetch 工具（已实测可抓取 HTML 正文，用于复核）。
- 原文语言：中文（站点为中文整理版），无需翻译，仅补充索引与说明。

## 三、处理流程

1. **收集**：逐页抓取并原文存档到 `source/`（codex-sdk.md / security-sdk.md），每文件带 3 行元信息头（来源 URL / 抓取日期 / 原文语言）+ 正文全文。
2. **加工**：生成 `00-说明.md`（本文件）与 `01-索引.md`（总览导航）；原文已是中文，正文保持原样。
3. **验证**：逐页核对——存档存在、非空、以元信息头开头；索引链接可解析、无断链；不触碰其他分类目录。
4. **交付**：分类目录内给出可整体拷贝的原文存档与索引；总入口见上级目录 `README.md`。

## 四、完成标准

断网环境下打开 `01-索引.md` 即可完整阅读 Codex SDK 与 Security SDK 中文文档，正文不依赖外网；指向 codex-docs.com 其它页面的站内链接离线不可用，仅作原始引用保留。
