1. **收集**：抓取并原文存档到 `source/app-server.md`（3 行元信息头：来源 URL / 抓取日期 / 原文语言 + 正文全文）。
2. **加工**：生成 `00-说明.md`（本文件）与 `01-索引.md`（总览导航）；原文已是中文，正文保持原样。
3. **验证**：存档存在、非空、以元信息头开头；索引链接可解析、无断链；不触碰其他分类目录。
4. **交付**：分类目录内给出可整体拷贝的原文存档与索引；总入口见上级目录 `README.md`。
